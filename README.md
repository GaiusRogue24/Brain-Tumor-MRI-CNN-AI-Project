# Brain-Tumor-MRI-CNN-AI-Project 

# Brain Tumor MRI Classification Using CNN

## Project Overview

This project implements a Convolutional Neural Network (CNN)
for classifying brain MRI images into four categories:

- Glioma
- Meningioma
- No Tumor
- Pituitary

## Dataset

The dataset was obtained from Kaggle and contains
7,200 MRI images:

- 5,600 training images
- 1,600 testing images

## Model

The CNN was implemented using PyTorch and trained for
5 epochs using the Adam optimizer and Cross-Entropy Loss.

## Results

Training Accuracy: 98.61%

Test Accuracy: 86.38%
